# 培训即组织设计

> 培训模块不是课程系统，而是把"真实工作"变成"培养过程"的组织操作系统。本洞察基于培训案例（案例集 training 目录）与培训核心思想（手册 training 章节）整理。

## 一句话核心

**人事云培训模块的本质，是把 CEO 的培养心智产品化为系统规则。** 案例中那些靠个人习惯完成的管理动作——渐进式授权、四问汇报、复述纪律、手册沉淀——全部变成可运行、可强制、可复盘的制度。

## 从案例事实到产品需求

| 案例事实 | 推导出的需求 | 产品能力 |
|---|---|---|
| 商务经理培养周期长，"一步一步来" | 长期一人一档，而非一次性课程记录 | 培养档案（一人一策） |
| 客户建档：范例 → 自己的想法 → 接手 | 任务级阶段状态机，每步有观察点与验收 | 带教协作（渐进式授权） |
| 报价三段式、预算三步法、四问框架 | 思维框架沉淀，按场景推送 | 框架库（授之以渔） |
| "不要发 AI 原文，说你自己复述的结果" | 复述纪律系统化，防止人变成转述工具 | AI 教练（AI 是脚手架） |
| "没有交接文档，一律不算有效工时" | 经验制度化闭环，不随人员流失 | 案例库与复盘（教别人干） |
| 试用期主线任务"兼具学习功能" | 真实业务任务 = 学习项目 | 真实任务学堂（以业务为教材） |

## 核心设计原则（与培训核心思想一一对应）

1. **以真实业务为教材** → 主线任务设计器：任务库 = 组织教案池，每个完成的任务沉淀一个"教案时刻"；
2. **授之以渔** → 框架库：先给"怎么想"的框架，用提问代替给答案；
3. **渐进式授权** → 四步状态机：示范 → 尝试 → 接手 → 独立，每步绑定观察点（质量、主动反馈、求助）；
4. **AI 是思考的脚手架** → 陪练 + 复述检测 + 质量底线对照，产出留痕、责任归人；
5. **培养的终点是教别人干** → 晋升验收 = 有下属任务在跑 + 有手册沉淀；
6. **按阶段一人一策** → 阶段诊断（新人/骨干/高管），每个阶段只设一个培养重点。

## 六大能力模块

1. **培养档案（一人一策）**：阶段诊断 → 单重点培养目标 → 方法匹配 → 周期复盘。产出个人成长档案。
2. **真实任务学堂（以业务为教材）**：主线任务设计器，注明学习意图，真实交付 + 管理者兜底 + 事后复盘。
3. **框架库（授之以渔）**：思维框架沉淀与场景化推送，提交前用框架自检。
4. **带教协作（渐进式授权 + 教别人干）**：任务四步状态机 + 师徒关系 + 晋升带教义务。
5. **AI 教练（AI 脚手架）**：模拟客户/上级的陪练；复述检测（相似度过高直接打回）；产出质量与基准对照。
6. **案例库与复盘（经验制度化）**：脱敏案例沉淀、案例讨论会、四问复盘模板、从复盘生成手册草稿。

## 深层洞察

### 培训是筛选的延续

试用期主线任务本质上是筛选博弈（见 recruitment/screening-game）的延续：管理者先设机制，员工通过行动暴露类型——"让他在试用期执行他的思路，看一看效果"。培训系统把"先筛选、后引导"制度化：主线任务既是培养，也是考察。

### 衡量单位的转变

通用 LMS 记"学了多少课、考了多少分"；本设计记"能独立做什么、能教别人什么"。**衡量单位变了，系统设计就全变了**——课程、证书不再是核心对象，任务、带教、复盘才是。

### 复述纪律是 AI 时代的制度创新

"不要发 AI 原文"从一句口头要求，变成系统强制规则（相似度检测打回）。这不是禁止 AI，而是**强制消化**：AI 可以梳理，但结论必须经过自己的判断与复述。这是 AI 原生组织把"人不能变成转述工具"产品化的尝试。

### 经验制度化的闭环

真实任务 → 复盘 → 手册 → 制度 → 新任务。个人经验一旦进入闭环，就不随人员流动流失（呼应"没有交接文档不算有效工时"）。培养的终点是组织能力，不是个人能力。

### 与"定价即组织设计"的呼应

薪酬洞察回答"用什么价格信号定义关系"，培训洞察回答"用什么培养机制定义成长"。两者共同指向 insight 仓库的核心问题：**如何用制度设计代替管理者直觉。**

- 薪酬：用外部渠道价格作锚点，利益结构代替管理者推动人；
- 培训：用状态机、观察点、复述纪律，把管理者的培养动作变成系统默认。

## 落地顺序

1. **MVP**：培养档案 + 主线任务 + 四问周报（含 AI 复述检测）——只覆盖新人试用期，案例里最痛、闭环最短的场景；
2. **二期**：带教协作状态机 + 框架库；
3. **三期**：案例库 + 手册/制度沉淀 + 管理者培养仪表盘。

> 判断标准始终只有一个：**员工在这里不是在"上课"，而是在做真事、被带教、被复盘。**
